# auto_pdf — 재직증명서 발급

양식을 고르고 입력창을 채운 뒤 **[양식에 채우기]** 를 누르면 A4 재직증명서 PDF 미리보기가 열립니다.
미리보기에서 인쇄 / PDF 저장·공유가 가능합니다.

## 양식

| 양식 | 내용 |
|---|---|
| 표준형 | 노란 세로칸(인적사항/재직사항) 격자 양식 — 주민등록번호·업체전화·확인자 포함, "부터 현재까지" |
| 기본형 | 인적사항/재직사항/회사정보 표 — 생년월일·용도·발급번호, 재직기간 자동 계산(N년 N개월) |

## 도장 자동 날인

'도장 자동 날인'을 켜면 입력한 이름으로 도장을 그려 찍습니다.

- 개인 도장(원형): 확인자 성명을 세로로 (4자 이상은 두 글자씩, 예: 남궁 / 민수) → `(인)` 자리
- 회사 직인(사각): 회사명 + '인'을 왼→오른쪽 줄 순서로 (예: 언더핀 → 언더 / 핀인) → `(직인)` / 대표이사 `(인)` 자리. `(주)`는 '주식회사'로 풀어 씀

한글 폰트(나눔명조·나눔고딕, OFL)는 `assets/fonts`에 들어 있어 오프라인에서도 동작합니다.

## 실행

```bash
flutter pub get
flutter run -d chrome
```

## 구조

- `lib/main.dart` — 양식 선택·입력 화면, 미리보기 화면 (`PdfPreview`)
- `lib/cert_pdf.dart` — 양식별 PDF 레이아웃, 도장(`personalSeal`, `companySeal`)
